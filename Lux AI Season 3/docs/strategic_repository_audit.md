Official combat semantics: movement first; SAP center damage equals public sap cost, eight neighboring cells get floored dropoff damage; only opposing units take SAP damage, so friendly-fire coefficient is exactly zero. Range is Chebyshev, map-bounded. Collision compares aggregate pre-SAP energy at post-movement tiles; equal stacks both lose. Orthogonal energy-void loss follows collisions, then energy recovery, spawning, map drift, score and match settlement. Unknown dropoff/void parameters use documented public bounds, never hidden match parameters in the Actor/controller.

Replay action alignment: action saved at record T caused observation T from T-1. Movement check on one remaining legal replay matched 3001/3003 movement actions to the previous transition versus 1280 to the next transition. New builder shifts record actions by one for outbound action/SAP anchors.

Official rewards are cumulative match wins, not incremental reward. Online wrapper must difference team wins; optional point shaping is reset-aware and separately logged. Whole 5-match episode time limit is a true task horizon in our wrapper (zero terminal bootstrap), while artificial rollout cuts bootstrap the final pre-cut observation.

Semi-MDP contract: one team decision epoch, one stored tau; all active units select once, no KEEP action. Any triggering unit event stops the whole option. Return sum gamma^k*r, TD bootstrap gamma^tau; primitive-time lambda convention uses (gamma*lambda)^tau. Per-agent clipped MAPPO surrogate uses each unit's mode+goal logprob and start-active mask, shared team advantage; never multiply 16 likelihood ratios. Actor behavior logprobs are recorded before updates. IL actor weights are retained; critic starts random.
